# واجبات مدرستي — نموذج واجهات تجريبي

## فتحه على الكمبيوتر

1. حمّل ZIP للفرع الذي يحتوي هذه التعديلات من GitHub عبر Code ثم Download ZIP.
2. اضغط بزر الفأرة الأيمن على ZIP واختر استخراج الكل.
3. افتح المجلد المستخرج، ثم افتح `index.html` بمتصفح Chrome أو Edge. لا تفتحه من داخل ZIP.
4. انتقل من صفحة البداية إلى الشاشة المطلوبة. لا يتطلب النموذج تثبيت برنامج أو إدخال بيانات حساب.

## الملفات المعتمدة

| الملف | الوظيفة |
|---|---|
| index.html | نقطة البدء وتعليمات المعاينة |
| dashboard.html | لوحة بيانات وسجلات توضيحية ثابتة |
| auth-setup.html | تصور الإعداد؛ أزرار الربط والتشغيل معطلة |
| assignments.html | أمثلة واجبات مع بحث وتصفية وتفاصيل محلية |
| DESIGN.md | المرجع البصري الوحيد |

ملفات `code.html` و`code(1).html` و`code(2).html` روابط انتقال للتوافق مع الأسماء القديمة. عدّل الملفات المعتمدة فقط.

## حدود النسخة

لا يوجد خادم أو OAuth أو اتصال بمدرستي أو تخزين مشفر أو حل أو تسليم أو إشعارات أو تصدير PDF. كل الدرجات والتوقيتات والأسماء والسجلات بيانات توضيحية. اختيار مرشحات الأرشيف لا يجلب بيانات حقيقية.

الشاشات الداخلية تحمل Tailwind من CDN وخطوطًا وأيقونات من Google؛ تتطلب اتصالًا بالإنترنت ويتلقى مقدمو تلك الموارد طلبات المتصفح. هذه الاعتمادات غير مجهزة للإنتاج أو للعمل الكامل دون اتصال. صفحة البداية تعمل دون اعتماد خارجي.

## الخطوة التالية

حسم طريقة تكامل مدعومة مع مدرستي قبل تنفيذ تسجيل الدخول أو الجلب أو الإرسال. بعد ذلك تُنفذ الحالات وفق ردود الخدمة الفعلية، مع معالجة انتهاء الجلسة وفشل الطلب ومنع التسليم المكرر. لا تُفعّل أي رسالة نجاح قبل وجود دليل من الخدمة.
